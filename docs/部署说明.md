## 二、数据库

五个独立业务库（utf8mb4 / utf8mb4_unicode_ci）：

`db_user`（用户中心）、`db_order`（服务与工单）、`db_health`（健康档案）、`db_notify`（消息通知）、`db_statistics`（统计报表）。

## 三、中间件编排

- 编排文件：项目内 `infra/docker-compose.yml`
- 虚拟机部署目录：`/opt/elderly-care/`
- 启动命令：`docker compose up -d`

## 四、后端服务接入配置（后续服务统一使用）

- Nacos 注册/配置中心：`192.168.11.133:8848`
- MySQL 连接串：`jdbc:mysql://192.168.11.133:3306/db_xxx?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai`
- Redis：`192.168.11.133:6379`，密码 `123456`

## 五、CentOS 7 部署踩坑记录

1. CentOS 7 已停止维护，yum 源需切换国内 vault 镜像：`https://mirrors.aliyun.com/centos-vault/7.9.2009/...`
2. `vault.centos.org` 通过 CloudFront 对大陆做地域封锁（403），需用国内 `centos-vault` 镜像。
3. `download.docker.com` 被墙，docker-ce 源改用：`https://mirrors.aliyun.com/docker-ce/linux/centos/...`
4. Docker 镜像拉取加速：`/etc/docker/daemon.json` 配置 `docker.m.daocloud.io` 等镜像。
5. Nacos 2.x 除 8848 外还依赖 gRPC 端口 9848/9849，采用 host 网络避免 Docker NAT 导致注册失败。
