# 社区智慧养老服务系统 部署说明

## 一、总体部署架构

| 部署位置 | 组件 |
|----------|------|
| VMware 虚拟机（CentOS 7，桥接 IP 192.168.11.133） | Docker：Nacos 2.3.2、MySQL 8.0、Redis 7（生产可再加 Nginx 托管前端） |
| Windows 宿主机 | 6 个 Spring Boot 服务（网关+5 微服务）、管理端前端（开发模式） |

## 二、虚拟机中间件部署（Docker）

### 2.1 系统准备（CentOS 7 已停止维护，需换国内源）
```bash
# 换阿里云 vault 源（vault.centos.org 对大陆 403）
mkdir -p /etc/yum.repos.d/backup
mv /etc/yum.repos.d/CentOS-*.repo /etc/yum.repos.d/backup/ 2>/dev/null
cat > /etc/yum.repos.d/CentOS-Base.repo <<'EOF'
[base]
name=CentOS-7.9.2009 - Base
baseurl=https://mirrors.aliyun.com/centos-vault/7.9.2009/os/x86_64/
enabled=1
gpgcheck=0

[updates]
name=CentOS-7.9.2009 - Updates
baseurl=https://mirrors.aliyun.com/centos-vault/7.9.2009/updates/x86_64/
enabled=1
gpgcheck=0

[extras]
name=CentOS-7.9.2009 - Extras
baseurl=https://mirrors.aliyun.com/centos-vault/7.9.2009/extras/x86_64/
enabled=1
gpgcheck=0
EOF
yum clean all
yum makecache
```

### 2.2 安装 Docker
```bash
yum install -y yum-utils
# download.docker.com 被墙，用阿里云 docker-ce 镜像源
cat > /etc/yum.repos.d/docker-ce.repo <<'EOF'
[docker-ce-stable]
name=Docker CE Stable - $basearch
baseurl=https://mirrors.aliyun.com/docker-ce/linux/centos/$releasever/$basearch/stable
enabled=1
gpgcheck=0
EOF
yum clean all && yum makecache
yum install -y docker-ce-24.0.9 docker-ce-cli-24.0.9 containerd.io docker-buildx-plugin docker-compose-plugin
systemctl enable --now docker
```

### 2.3 镜像加速与防火墙
```bash
mkdir -p /etc/docker
cat > /etc/docker/daemon.json <<'EOF'
{ "registry-mirrors": ["https://docker.m.daocloud.io", "https://dockerproxy.com"] }
EOF
systemctl daemon-reload && systemctl restart docker

systemctl start firewalld
for p in 8848 9848 9849 3306 6379; do firewall-cmd --permanent --add-port=${p}/tcp; done
firewall-cmd --reload
```

### 2.4 启动中间件（编排文件见项目 infra/docker-compose.yml）
```bash
mkdir -p /opt/elderly-care/mysql/init /opt/elderly-care/mysql/data \
         /opt/elderly-care/redis/data /opt/elderly-care/nacos/logs
cd /opt/elderly-care
# 将 docker-compose.yml 与 mysql/init/init.sql 上传到此目录后：
docker compose up -d
docker compose ps
```
- Nacos 控制台：http://192.168.11.133:8848/nacos（nacos/nacos）；采用 host 网络并映射 8848/9848/9849；
- MySQL：192.168.11.133:3306（root/123456）；首次启动自动执行 init.sql 创建 5 个库；
- Redis：192.168.11.133:6379（密码 123456，AOF 持久化）。

### 2.5 发布 Nacos 共享配置

系统公共配置（MySQL 账号密码、Redis 连接、JWT、MyBatis-Plus）统一放在 Nacos 配置中心的共享配置 `shared-datasource.yaml`（DEFAULT_GROUP），各服务通过 bootstrap.yml 的 shared-configs 引用。部署时需在 Nacos 控制台「配置管理 → 配置列表 → 新建配置」创建该配置（Data ID：`shared-datasource.yaml`，格式：YAML，内容与项目 `infra/shared-datasource.yaml` 一致），或调用 Open API 发布：

```bash
curl -X POST 'http://192.168.11.133:8848/nacos/v1/cs/configs' \
  --data-urlencode 'dataId=shared-datasource.yaml' \
  --data-urlencode 'group=DEFAULT_GROUP' \
  --data-urlencode 'type=yaml' \
  --data-urlencode 'content=@infra/shared-datasource.yaml'
```

## 四、后端服务部署

### 4.1 构建
```bash
cd E:\DeepSeekHarnessWork\project-02-Graduationthesis
mvn clean package -DskipTests
```
各服务产物：`{服务名}/target/{服务名}-1.0.0.jar`。

### 4.2 启动（IDEA 或命令行，按依赖顺序）
| 顺序 | 服务 | 端口 | 启动类 |
|------|------|------|--------|
| 1 | gateway | 8080 | GatewayApplication |
| 2 | user-center | 8081 | UserCenterApplication |
| 3 | order-work | 8082 | OrderWorkApplication |
| 4 | health-record | 8083 | HealthRecordApplication |
| 5 | notify | 8084 | NotifyApplication |
| 6 | statistics | 8085 | StatisticsApplication |

命令行示例：`java -jar gateway/target/gateway-1.0.0.jar`。
启动后 Nacos 服务列表应出现全部 6 个服务。各服务 Knife4j 文档：`http://localhost:{端口}/doc.html`。

### 4.3 关键配置
- Nacos 地址、MySQL/Redis 连接、JWT 密钥位于各服务 `bootstrap.yml`/`application.yml`，修改 VM_IP 时按文件更新。

## 五、前端部署

### 5.1 管理端
```bash
cd frontend/admin-web
npm install --registry=https://registry.npmmirror.com
npm run dev        # 开发模式 http://localhost:5173
npm run build      # 生产构建 → dist/
```
生产方案（可选）：虚拟机 Docker 增加 Nginx 容器，托管 dist 并将 `/api` 反向代理至网关。

### 5.2 微信小程序
微信开发者工具导入 `frontend/family-miniapp`（测试号），勾选「不校验合法域名」；真机预览将 `utils/config.js` baseUrl 改为电脑局域网 IP。

## 六、常见问题
| 现象 | 处理 |
|------|------|
| vault.centos.org 403 | 使用阿里云 centos-vault 镜像 |
| download.docker.com 连接被重置 | 使用阿里云 docker-ce 镜像 |
| 微服务注册失败 | Nacos 需开放 8848/9848/9849 端口（host 网络已处理） |
| 接口 404 | 对应服务未重启加载新代码 |
| 401 | token 缺失/过期/已登出，重新登录 |
