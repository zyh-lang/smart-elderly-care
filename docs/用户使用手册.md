## 2. 管理端使用说明

### 2.1 启动与登录
1. 确保 6 个后端服务已启动（网关 8080 + 5 个微服务）；
2. 在 `frontend/admin-web` 执行 `npm run dev`；
3. 浏览器访问 http://localhost:5173，输入 admin/123456 登录。

### 2.2 数据看板
首页展示订单总数、总营收、工单总数、平均满意度四个卡片，以及近 7 天订单趋势图与服务类型排名图。

### 2.3 用户管理
- 列表支持按用户名/姓名搜索、分页；
- 「新增用户」填写用户名、密码、手机号、角色、姓名创建账号；
- 「禁用/启用」切换用户状态（管理员账号不可禁用）。

### 2.4 服务管理
- 「新增服务」填写名称、类型、价格、说明；
- 编辑与删除服务目录（删除为逻辑删除）。

### 2.5 订单管理
- 查看全部订单及状态；
- 对「待派单」订单点击「智能派单」，系统自动选择最优服务商并生成工单。

### 2.6 工单管理
- 查看工单及状态（已派单/服务中/待验收/已完成/已评价/已取消/已投诉）；
- 对未完结工单可执行「取消」。

### 2.7 健康档案
- 左侧选择老人，右侧查看/编辑基本档案、录入健康指标、管理用药记录。

### 2.8 消息中心
- 查看收到的站内信，点击未读消息标记为已读。

### 2.9 老人管理
- 查看全部老人档案，支持新增/编辑/删除老人；
- 新增或编辑时可「绑定家属」账号并填写与家属的关系；绑定后该家属在小程序端即可为老人下单、查看健康档案。

### 2.10 服务商工作台（服务商角色）
- 服务商账号（provider03/123456 等）登录后自动进入工作台，菜单仅显示「服务商工作台」与「消息中心」；
- 对「已派单」工单点击「接单（开始服务）」，对「服务中」工单点击「完成服务」，完成后等待家属验收。

## 3. 微信小程序家属端使用说明

### 3.1 运行准备
1. 微信开发者工具导入 `frontend/family-miniapp`，AppID 选择测试号；
2. 「详情 → 本地设置」勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」；
3. 真机预览时把 `utils/config.js` 的 baseUrl 改为电脑局域网 IP。

### 3.2 登录
使用 family01/123456 登录。

### 3.3 首页下单
1. 浏览服务列表，点击「立即下单」；
2. 选择服务对象（老人）并填写服务地址；
3. 确认下单，订单进入待派单状态。

### 3.4 订单与工单
- 「订单」页查看我的工单及状态；
- 点击进入工单详情：
  - 待验收 → 点「验收」；
  - 已完成 → 点「评价」，滑动评分并提交；
  - 服务中/待验收 → 可「投诉」；
  - 未完结工单 → 可「取消工单」。

### 3.5 健康档案
- 顶部切换老人；
- 查看基本档案、录入血压/血糖/心率/体温/体重指标、查看用药记录。

### 3.6 消息中心
查看系统推送的工单消息，点击标记已读。

## 4. 常见问题
| 问题 | 处理 |
|------|------|
| 前端请求 401 | 重新登录；确认 Authorization 头带 Bearer 前缀 |
| 接口 404/NoResourceFound | 对应微服务未启动或未重启加载新代码 |
| 服务注册不上 Nacos | 检查 Nacos 9848/9849 gRPC 端口与网络连通 |
| 小程序请求失败 | 检查「不校验合法域名」是否勾选、baseUrl 是否正确 |
