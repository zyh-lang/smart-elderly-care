## 4. 联调测试

完整业务链路联调通过：
家属小程序下单 → 管理端/Apifox 智能派单（Feign 拉取服务商）→ 服务商开始/完成服务 → 家属验收 → 评价 →（每步状态变更异步推送站内信）→ 统计报表聚合展示（Feign + Redis 缓存）。

## 5. 性能测试说明

- 方案：JMeter 对网关下单接口做并发压测（如 50 并发 × 100 次），观察响应时间与错误率；
- 架构保障：网关 Sentinel QPS 限流、派单分布式锁、报表 Redis 缓存；
- 结论：常规并发下核心接口响应正常；限流与防重复派单机制在压测中可验证生效。

## 6. 缺陷记录与修复

| 编号 | 缺陷描述 | 原因 | 处理 | 状态 |
|------|----------|------|------|------|
| BUG-01 | 网关启动报 Bean 重复定义 | SentinelGatewayFilter 与 SCA 自动配置冲突 | 删除手动 Bean，仅保留规则加载 | 已修复 |
| BUG-02 | 网关启动报 Redis 模板类型错误 | @Resource 按字段名注入到阻塞版模板 | 字段改名 reactiveStringRedisTemplate | 已修复 |
| BUG-03 | lb:// 路由不可用 | gateway 未自动引入 LoadBalancer | 显式添加 spring-cloud-starter-loadbalancer | 已修复 |
| BUG-04 | 工单派给无登录账号的服务商，无法操作 | 种子数据服务商未绑定登录账号 | 补 provider02/03 账号并修正关联 | 已修复 |
| BUG-05 | 服务目录种子数据重复 | SQL 脚本重复执行 | 清理重复数据并注明脚本只执行一次 | 已修复 |
| BUG-06 | IDEA 中依赖标红 | 项目级 maven.config 仓库重定向与 IDEA 不一致 | 移除重定向，命令行显式传参 | 已修复 |
| BUG-07 | 编辑老人后绑定重建失败 | 逻辑删除行占用唯一键，重新插入冲突 | 改用 ON DUPLICATE KEY UPDATE 幂等重建 | 已修复 |
| BUG-08 | 新增老人小程序下单选不到 | 新增老人未绑定家属账号 | 老人管理支持绑定家属并自动建立绑定关系 | 已修复 |
| BUG-09 | 派单后管理员消息中心无消息 | 通知未发给执行派单的操作者 | 派单成功消息同步通知操作者 | 已修复 |
| BUG-10 | 总营收口径偏差 | 统计包含未完成订单金额 | 仅统计已完成订单，验收时同步订单状态 | 已修复 |

## 7. 测试结论

系统核心功能全部通过验证：登录鉴权闭环、四角色 RBAC、下单与智能派单、工单状态机、评价投诉、健康档案、老人管理、服务商工作台、消息推送、统计报表均符合需求；Nacos 注册与配置中心（共享配置统一管理）运行正常；安全机制（401/403 拦截、状态机校验、防重复派单）验证有效；缺陷已全部修复并回归通过，系统达到可交付状态。
